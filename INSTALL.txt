IMAGE FILES TO PDF 1.5.3 - SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/ImageFilesToPDF

Verifying what you downloaded
=============================

Every file in the release is signed with a GitHub build attestation. With the
GitHub CLI installed, from the folder you downloaded them into:

    gh attestation verify "Image-Files-to-PDF.jxa" \
        --repo resoltico/ImageFilesToPDF
    shasum --check SHA256SUMS

Requirements
============

macOS 12.3 or later.

The Shortcuts app is macOS 12 and later; 12.3 is the point at which its
JavaScript engine supports everything this action uses.

Runtime tools
=============

Open Terminal and run:

    brew install vips pdfcpu

Install the Quick Action
========================

1. Open the Shortcuts app.
2. Create a new shortcut.
3. Open the shortcut details.
4. Enable "Use as Quick Action".
5. Enable Finder.
6. Configure the shortcut to receive Files from Finder.
7. Add "Run JavaScript for Mac Automation".
8. Delete the example code in that action.
9. Paste the complete contents of:

       dist/Image-Files-to-PDF.jxa

10. Save the shortcut as "Image Files to PDF".

Use it
======

Select image files or folders in Finder and run the Quick Action. Selected
folders are searched recursively. Each image occupies its own PDF page; this
is not a collage or contact-sheet action.

"One PDF — one image per page" combines the pages into one file.
"Separate PDFs — one page per image" saves one single-page file per image.
With one image both options make one single-page PDF, but use different
filename prefixes. The settings window explains the count and save location.
Pages use JPEG compression without changing the original image files.

Review any selection problems, choose the settings, and click Create. With
stepwise dialogs, the last dialog confirms the settings before files are
created. Completion reports the PDFs saved and anything not converted.

Remove it
=========

1. In the Shortcuts app, delete the "Image Files to PDF" shortcut.
2. To forget the settings it remembered, open Terminal and run:

       defaults delete com.resoltico.ImageFilesToPDF

That is everything it leaves on your Mac. It keeps one preferences entry,
under that name, holding the page setup of your last run, and nothing about
your images. Its working files go in the system temporary folder and are
cleared away as each run ends; a run that could not save a finished PDF leaves
them in place on purpose, and the message says where they are.

vips and pdfcpu are yours rather than this action's, and anything else on your
Mac may be using them, so they are left alone. Remove them with

    brew uninstall vips pdfcpu

if nothing else needs them.
