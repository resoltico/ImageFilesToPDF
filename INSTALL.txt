IMAGE FILES TO PDF 3.0.0 - SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/ImageFilesToPDF

Requirements
============

macOS 12.3 or later, with Shortcuts. The Quick Action needs no Node.js runtime.
Install its command-line tools in Terminal:

    brew install vips pdfcpu

vipsheader comes with vips. pdfcpu must be a stable release, 0.16.4 or later.
To upgrade it:

    brew update
    brew upgrade pdfcpu

Verify a download
=================

The release workflow attests the JXA, checksum manifest, installation
instructions and license. With GitHub CLI installed, from the download folder:

    gh attestation verify Image-Files-to-PDF.jxa --repo resoltico/ImageFilesToPDF
    shasum --check SHA256SUMS

Install the Quick Action
========================

1. Open Shortcuts and create a new shortcut.
2. In its details, enable "Use as Quick Action" and Finder.
3. Configure it to receive Files from Finder.
4. Add "Run JavaScript for Mac Automation".
5. Replace the example code with the COMPLETE contents of the downloaded
   Image-Files-to-PDF.jxa. In a repository checkout, that file is at
   dist/Image-Files-to-PDF.jxa.
6. Name the shortcut "Image Files to PDF".

To install a newer build, replace the complete pasted script. Download
checksums do not verify an installed pasted copy.

Use it
======

Select images or folders in Finder and run Image Files to PDF. Review any items
that cannot be included, choose the page settings, then click Create. Choose one
PDF with a page for each image, or one PDF per image. PDFs of images found in a
selected folder are saved in that folder; PDFs of images selected directly are
saved beside them. Originals are never modified.

A JPEG that is embedded unchanged keeps its metadata, including any location,
inside the PDF.

If a PDF cannot be saved where it belongs, it is saved to Downloads, or failing
that to a temporary copy, and completion shows where. Move recovered work
somewhere permanent promptly: macOS can clear temporary storage.

README.md in the repository describes the settings, supported images and output
in full. HEADLESS.md describes command-line use.

Remove it
=========

1. Delete the "Image Files to PDF" shortcut in Shortcuts.
2. To forget the page settings shared by installed copies, run:

       defaults delete com.resoltico.ImageFilesToPDF

The preference domain stores page settings only. A message that the domain
does not exist means there is nothing to remove. Working files are normally
cleaned up; inspect any recovery or workspace location a run reported before
removing it. Your images and their PDFs stay until you remove them.

vips and pdfcpu may be used by other software. If nothing needs them, remove:

    brew uninstall vips pdfcpu
