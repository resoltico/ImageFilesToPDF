IMAGE FILES TO PDF 1.5.4 - SHORTCUTS INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/ImageFilesToPDF

Requirements
============

macOS 12.3 or later, with Shortcuts. The Quick Action needs no Node.js runtime.
Install its command-line tools in Terminal:

    brew install vips pdfcpu

vipsheader comes with vips. Requires stable pdfcpu 0.16.4 or later. To upgrade:

    brew update
    brew upgrade pdfcpu

pdfcpu runs with --conf disable, without personal configuration, fonts or
certificates. See QA.md in the repository for current verification limits.

Verify a download
=================

The release workflow attests the JXA, checksum manifest, installation
instructions and license. With GitHub CLI installed, from the download folder:

    gh attestation verify "Image-Files-to-PDF.jxa" \
        --repo resoltico/ImageFilesToPDF
    shasum --check SHA256SUMS

Install the Quick Action
========================

1. Open Shortcuts and create a new shortcut.
2. In its details, enable "Use as Quick Action" and Finder.
3. Configure it to receive Files from Finder.
4. Add "Run JavaScript for Mac Automation".
5. Replace the example code with the COMPLETE contents of the downloaded
   Image-Files-to-PDF.jxa. In a repository checkout, that file is at
   dist/Image-Files-to-PDF.jxa.
6. Name the shortcut "Image Files to PDF".

To install a changed build, replace the complete pasted script. Download
checksums do not verify an installed pasted copy.

Use it
======

Select images or folders in Finder and run the Quick Action. Folder traversal
is recursive; it skips hidden entries, links, packages and unsupported names.
Explicitly selected hidden images are considered; selected links/packages are
refused. Duplicate images are converted once, in natural full-path order.

Supported extensions: jpg, jpeg, png, heic, heif, tif, tiff, webp and avif.
Actual content must be a supported single-image raster. Animated, multipage,
corrupt, unknown or disguised unsupported content is refused.

Review selection problems, choose the six page settings, then click Create.
Stepwise dialogs end with confirmation. Each image gets its own centred,
PDF page without cropping or enlargement. Originals stay intact. PNG/TIFF
use lossless encoding. Eligible JPEGs retain their bytes and embedded metadata;
other JPEG/HEIF/WebP inputs use JPEG encoding when normalized. Maximum
resolution limits downsampling, and JPEG quality affects JPEG re-encoding only.

"One PDF - one image per page" combines the pages into one document.
"Separate PDFs - one page per image" creates a single-page document per image.
Images found through a selected folder save there; explicit files save beside
their source. A combined PDF uses the first ordered image's destination.
Combined names are Images YYYY-MM-DD at HH.MM.SS.pdf (local time). Separate
names use the sanitized source stem; same-run stem conflicts add the lower-case
extension. Different spellings the destination treats as one name are disambiguated.
Existing entries are never overwritten; collisions use " 2", " 3", etc.

Combined mode publishes no subset after a candidate failure. Separate mode
continues ordinary failures, while cancellation, cleanup or software faults can
stop remaining work. Completion identifies saved/recovered work, failures and
work not started. Follow any reported recovery or unconfirmed-candidate path;
validated recovery first uses Downloads under the intended filename, then a
confirmed temporary copy if Downloads is unavailable. Show in Finder opens the
reported recovery. Retained or unreadable workspaces remain for inspection;
the next valid conversion reclaims unretained work owned by dead processes.

Remove it
=========

1. Delete the "Image Files to PDF" shortcut in Shortcuts.
2. To forget the page settings shared by installed copies, run:

       defaults delete com.resoltico.ImageFilesToPDF

The preference domain stores page settings only. Working files are normally
cleaned; inspect any intentionally retained recovery/workspace locations named
by a run before removing them. The action does not automatically delete your
source images or saved PDFs.

vips and pdfcpu may be used by other software. If nothing needs them, remove:

    brew uninstall vips pdfcpu
