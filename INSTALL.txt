IMAGE FILES TO PDF 4.0.0 - INSTALLATION

Source, releases and build attestation:

    https://github.com/resoltico/ImageFilesToPDF

Requirements
============

macOS 13.5 or later with Shortcuts and Node.js 26.13.1 or later.
The Finder floor comes from the Node.js platform requirements. Finder execution
on macOS 13.5–14 has not been tested.

    https://github.com/nodejs/node/blob/v26.13.1/BUILDING.md#platform-list

Installing the tools
====================

macOS
-----

Install libvips with vips and vipsheader, and stable pdfcpu 0.16.4 or later.

Homebrew supports macOS 15 and later on Apple Silicon.

    brew install node vips pdfcpu

MacPorts provides vips and pdfcpu. Use the official Node.js installer while
the nodejs26 port is at 26.13.0, below the 26.13.1 minimum.

    sudo port install vips pdfcpu

Upstream downloads include the Node.js macOS installer, libvips sources and
build instructions, and pdfcpu release binaries.

    https://nodejs.org/en/blog/release/v26.13.1
    https://www.libvips.org/install.html
    https://github.com/pdfcpu/pdfcpu/releases

Finder reads absolute directories from /etc/paths and then the files in
/etc/paths.d in name order, with numeric prefixes ordered numerically when
both names have one. It appends /opt/homebrew/bin, /usr/local/bin and
/opt/local/bin, keeping each directory's first occurrence. If setup fails,
use Choose… to select each missing or unusable executable. Finder remembers
and checks a chosen path first on every run.

Linux and Windows
-----------------

On Linux, use distribution packages or upstream releases. On Windows, use
upstream installers and executable distributions or your choice of package
manager. On both platforms put the executable directories on PATH.

Verify a download
=================

The release workflow attests every release file. With GitHub CLI installed,
from the download folder:

    gh attestation verify Image-Files-to-PDF.jxa --repo resoltico/ImageFilesToPDF
    shasum --check --ignore-missing SHA256SUMS

Install the CLI
===============

Install Node.js 26.13.1 or later, libvips and stable pdfcpu 0.16.4 or later,
and put vips, vipsheader and pdfcpu on PATH. Then install the command with npm,
which comes with Node.js:

    npm install -g image-files-to-pdf

Update with "npm install -g image-files-to-pdf@latest" and remove with
"npm uninstall -g image-files-to-pdf". On Windows use PowerShell 7.4 or later
for UTF-8 stdout redirection. See HEADLESS.md in the repository for settings and
platform prerequisites.

    image-files-to-pdf --settings settings.json -- "photo 1.jpg" folder

Install the Quick Action
========================

1. Open Shortcuts and create a new shortcut.
2. In its details, enable "Use as Quick Action" and Finder.
3. Configure it to receive Files from Finder.
4. Add "Run JavaScript for Mac Automation".
5. Replace the example code with the COMPLETE contents of the downloaded
   Image-Files-to-PDF.jxa. In a repository checkout, that file is at
   dist/Image-Files-to-PDF.jxa.
6. Name the shortcut "Image Files to PDF".

To install a newer build, replace the complete pasted script. Download
checksums do not verify an installed pasted copy.

Use it
======

Select images or folders in Finder and run Image Files to PDF. Review any items
that cannot be included, choose the page settings, then click Create. Choose one
PDF with a page for each image, or one PDF per image. PDFs of images found in a
selected folder are saved in that folder; PDFs of images selected directly are
saved beside them. Originals are never modified.

Exactly one admitted image produces a PDF named after the image in either mode,
for example photo.pdf, then photo 2.pdf if occupied. A combined PDF of two or
more images keeps the Images YYYY-MM-DD at HH.MM.SS.pdf name. HDR JPEG photos
are converted as standard-range images without their gain maps.

A JPEG that is embedded unchanged keeps its metadata, including any location,
inside the PDF.

If saving fails, the action attempts verified recovery in Downloads. It keeps
the verified PDF in a private durable workspace when Downloads recovery cannot
be confirmed. Completion reports the actual location or any remaining uncertainty.

README.md in the repository describes the settings, supported images and output
in full. HEADLESS.md describes command-line use.

Remove it
=========

1. Delete the "Image Files to PDF" shortcut in Shortcuts.
2. To forget the page settings and chosen executable locations shared by
   installed copies, run the following command.

       defaults delete com.resoltico.ImageFilesToPDF

A message that the domain does not exist means there is nothing to remove.
Working files are normally cleaned up. Inspect any recovery or workspace location a run reported before
removing it. Your images and their PDFs stay until you remove them.

vips and pdfcpu may be used by other software. If nothing needs them, follow
your installation method's removal instructions.
